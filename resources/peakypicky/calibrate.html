CalibrationBuilder

Turn a blue-dextran void run + standard-protein runs into a Kav-based MW calibration file

Drop three (or more) Cytiva/UNICORN export .zip files from a single column: one blue-dextran run to establish the void volume, and one or more runs with proteins of known molecular weight. This page fits log10(MW) = intercept + slope·Kav, Kav = (Ve−V0)/(Vt−V0), and produces a calibration JSON file that goes into calibrations/ alongside this app — see calibrations/README.md.
